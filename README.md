# LCARS_strip
A 1U ultrawide (1424x280) touchscreen fleet-status panel for a Netdata parent.
Retro hi-fi aesthetic: EasyAmp chrome + NeonPulse CRT scanlines + LCARS accents,
with needle / LED-digital / retro VU meters and tap-to-drill node detail.

**Status:** first-pass mockup (fake data). Real build reads the local Netdata
API on the parent (Starbase2). GPLv3.
